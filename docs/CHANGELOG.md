The build history that used to sit in `CLAUDE.md` "Status", oldest first, moved here by the 8b pass
(2026-09-28) so the project memory stays short. Each entry names the iteration (`docs/iterations.md`) and the
§2 decisions (`Q…` in `ARCHITECTURE.md`) it introduced; the decisions themselves are the normative record.
